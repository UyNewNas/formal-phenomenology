# 解释选择登记

版本：v0.1，2026-09-17。

## 证据层与形式层

本项目区分四种记录：`MODEL` 是人为规定的形式模型；`FORMAL` 是由定义和前提推出的结果；`READING` 是需要原典支持的解释；`QUESTION` 是尚待解决的问题。证明通过不会自动将 `MODEL` 升格为某位哲学家的 `READING`。

来源阅读状态见 [SOURCES.md](SOURCES.md)。本页的登记不是学说真伪的裁决，而是便于修改和比较解释的接口。

## 词汇映射

| 代码 | v0.1 中的严格含义 | 解释状态与尚缺内容 |
|---|---|---|
| `Phenomenon` | 被量化的对象类型 | MODEL；没有规定对象如何个体化，也未承诺现象可以完全对象化 |
| `appears p` | 模型中 p 被标记为显现 | MODEL；未编码显现过程、给予性或体验强度 |
| `Horizon` | 本模型允许谈论的视域类型 | MODEL；必须交代是实际、可达、可能还是理想视域 |
| `situated p h` | h 是 p 的相关视域 | MODEL；不是把一切视域都当作可以交换的容器 |
| `Aspect`、`presents p a` | 选定描述语言中的侧面及关联 | MODEL；不等于无结构的感觉数据，也不等于信息比特 |
| `admits h a` | h 在模型中容纳侧面 a | MODEL；没有度量，也不直接表示概念理解或意向充实 |
| `Exhausts p h` | h 容纳所有被编码为 p 的侧面 | MODEL；仅相对于选定的侧面词汇，不是对真实经验已经穷尽的宣称 |
| `NonExhaustible p` | 每个相关 h 都不能穷尽 p | MODEL；不是马里翁“饱和”的定义 |

把“侧面”当作集合论上可指认的项，是这一版模型的实质假设。日后若文本要求意义在经验中生成，而非预先列出侧面，就应建立替代模型，而不只给旧变量改名。

## A、B、C 的归属

**A — `UniversalStructure`。** 每个显现都有至少一个相关视域。它是待检验的结构性候选命题；尚未证明它在当前编码下忠实表达梅洛-庞蒂的任何具体段落。

**B — `ClosureBridge`。** 每个已经有相关视域的显现，存在一个相关视域穷尽它。这是特意加入的压力测试前提。代码与文档均不将 B 当作梅洛-庞蒂的主张。B 也不要求“最初的那个视域”本身穷尽现象；它只是另一个存在断言。

**C — `HasExcess`。** 存在显现，不能被任何相关视域穷尽。名称中的 `Excess` 是当前模型的简写，并没有把直观过剩、事件性、给予性、不可预期性或强度编码进去。将 C 对应饱和现象，仍需要额外论证。

因此 `minimal_conflict` 定位的是 **这三条形式命题** 的联合矛盾与逐条删除后的模型，不是完整学说的最小公理化。

## 三个容易偷换的地方

### 1. 结构不等于封闭

从 `Structured p` 到 `Captured p` 需要额外前提。仅仅都用“视域”这个词，不会产生这一步蕴含。将前者叫“受视域制约”、再把后者也叫“受视域制约”，会掩盖真正不同的命题。

### 2. 无法穷尽不等于完全没有视域

`splitModel` 与 `expandingModel` 的现象都实际显现，而且实际有相关视域。它们的不可穷尽性并不来自空论域。

`unsituatedModel` 专门检验另一个边界：所有类型非空，现象显现，但没有任何 `situated` 关系。此时 `NonExhaustible` 的全称条件因没有相关视域而成立，`ClosureBridge` 也因结构前提不成立而成立。这是明确展示的空真情形，不用它解释饱和经验。

如果未来将“实际有相关视域”并入 C 的定义，那么 B 和这个更强的 C 已经足以冲突，A 就不再是最小冲突核所必需。修改定义后必须重做最小性审计。

### 3. 无限多个侧面不等于饱和

有限的 `splitModel` 就能区分逐一覆盖与整体覆盖。自然数模型只是展示持续扩展；不声称哲学意义上的过剩可以用侧面数量或信息量刻画。`completedModel` 加入一个理想全覆盖视域后，结论改变：把哪些视域放进量词域，本身就是模型选择。

## 从对话直觉到文献问题

项目起点包含过强的口头概括。以下内容不能作为现成公理进入代码：

- “梅洛-庞蒂的视域必然把经验封闭在人类尺度之内。”
- “马里翁的饱和现象必然没有任何视域。”
- “马里翁明确把梅洛-庞蒂称为去主体化不彻底的前辈。”

前两项需要区分文本、时期与“限制”的含义；第三项尚未定位直接原文。应先建立段落卡，再决定保留、削弱或撤回解释。

## 当前不涉及的结构

主体、身体图式、时间、他者、意向活动、前反思经验与给予方式，都没有在 v0.1 中被声称已经刻画。后续编码应说明：新增结构解决了哪一项解释缺口、对哪些形式结果有影响、有哪些相反见证。
