## 3. Interpretive consequence for the current encoding

This source materially strengthens the **secondary** baseline for the existing three-axis split:

1. **related / situated horizon**: a phenomenon can still be discussed in relation to one or several horizons;
2. **conditioning / prior delimitation**: the horizon can function as a condition that restricts appearing;
3. **exhaustion / capture**: remaining within, filling, or exceeding one or several horizon arrangements is a different question from whether horizon is a prior condition.

Accordingly, Llorente 2015 supports the project’s existing discipline rather than forcing a new primitive:

- `Independent` remains only a weak model interface for absence of a `conditions` witness; it must **not** be renamed `Horizonless` or treated as full Marion saturation.
- `NonExhaustible` remains an independent extensional axis over the project’s selected aspects; it must **not** be identified with saturated phenomenality.
- `Captured` remains existential exhaustive coverage in the project model; a secondary author’s use of “saturating a horizon” does not license `Captured = Saturated`.
- Nothing in the inspected source supplies the extensional theorem `Captured p → Conditioned p`, nor the stronger same-horizon bridge `situated p h ∧ Exhausts p h → conditions p h`.

Therefore the strongest current formal answer is unchanged: bare horizon structure does not entail closure, and `Independent → NonExhaustible` on actual appearances requires exactly exclusion of an appearing `Captured ∧ Independent` witness; producing a conditioning witness additionally needs the already-isolated captured-domain stability premise.
