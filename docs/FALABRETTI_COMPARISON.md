## 2. 为什么它是重要 prior art

这不是一般的 Marion 或 Merleau-Ponty 二手文献，而是直接把 *Phenomenology of Perception* 与 *Étant donné* 放在同一比较问题中的论文。它因此改变本项目的原创性边界：

- “比较 Merleau-Ponty 与 Marion 的现象学”本身已有明确前人工作；
- “Merleau-Ponty 的开放／不可穷尽视域与 Marion 的 donation / saturation 作对照”也不能作为本项目新发现；
- 本项目若有独立增量，只能落在**明确区分 related / conditioning / exhaustive 三轴、隔离 bridge、给出可机核反模型与前提诊断**，而不是比较配对本身。

## 3. 对 Merleau-Ponty 侧的直接重合

论文期刊 p. 90（PDF page index 3）的论述与本项目首问高度重合：Falabretti 将知觉描述为不能化约成封闭经验，知觉意义处于持续开放的时空 horizon field 中；随后又明确说知觉不会穷尽被知觉者或知觉行为本身。

这与本项目已经直接核对的 Merleau-Ponty 原典方向一致，因此应将其归类为**已有比较研究中的同题解释**，而不是把“开放视域／不穷尽”包装成项目的新历史发现。Lean 的 `UniversalStructure ↛ ClosureBridge` 仍然是对一个中性关系语言的机核逻辑诊断；它不因这篇论文而失效，也不因换成 Lean 就获得历史原创性。

## 4. 对 Marion 侧的竞争解释

论文期刊 p. 98（PDF page index 11）把 saturated phenomenon 概括为：没有渐进综合，并以“没有 horizon、而是 overflowing presence”的方式表述，同时讨论 intuition excess、不可预期／不可承受／不可观测等特征。

这条表述必须作为**竞争 secondary reading**记录，而不能被项目直接采纳为默认编码。理由是：

1. Marion 1996 primary text p. 117 已被本项目直接从出版者索引读取；作者明确警告一般取消 horizon 会阻止 manifestation，问题在于 horizon 的先行限定作用。
2. 同一 primary text p. 118 又区分一个 horizon、多个 horizons、超过 horizon、乃至组合不足等多种关系。
3. Murga 2024 与 Djian 2018 进一步提供“非形而上学 horizontality／horizon-as-condition”方向的同题 prior art。

因此 Falabretti 的 `no horizon` 表述对本项目的价值恰好是提醒：**二手文献内部也存在解释分歧。** 它不能推翻 `situated / conditions` 的分层，也不能把 `Horizonless` 升级成 Marion saturation 的默认历史归属。

## 5. Marion 是否直接针对 Merleau-Ponty

论文期刊 p. 88（PDF page index 1）明确提醒：作者不能假定 Marion 会如何直接解释 Merleau-Ponty；并称 Merleau-Ponty 在 *Étant donné* 中处于边缘位置，只被明确引用三次，而且都是脚注。作者还说明 *Étant donné* 并不直接回答他所提出的 Merleau-Ponty / Marion 比较问题。

这对仓库已有未决项有直接影响：当前没有证据支持把“Marion 明确把 Merleau-Ponty 当作去主体化不彻底的前辈”写成已确立历史断言。Falabretti 反而提供一个具体的 caution：至少在这项直接比较研究中，这种强直接归属被明确避免。

## 6. 复用／不复用决定

本轮不新增 Lean predicate、theorem 或外部依赖。

- **复用**：将 Falabretti 作为直接比较 prior art 与竞争解释来源，限制项目的新颖性表述，并强化“强 Marion→Merleau-Ponty 直接批评”不得未经原典支持采用。
- **不复用为定义**：不把其 “no horizon” 二手概括直接翻译成 `Horizonless`，因为它与已核验 Marion 1996 primary text 以及 Murga / Djian 的解释空间存在张力。
- **不新增形式 API**：该论文没有暴露出首问当前三轴语言缺少的新逻辑结构；相反，它说明继续增加自由谓词会把解释争议伪装成模型自由度。

## 7. 对停止门的影响

这项 prior art **不能代替** *Being Given* pp. 209–212、225–226 或 *Étant donné* pp. 292–297、314–315 的 direct-primary review，因此停止门仍开放。

但它把最终短稿的原创性边界进一步冻结为：比较传统已存在；本项目的可交付增量是**证据分层 + 形式接口 + 反模型/bridge 审计 + 可复现验证**，而不是声称首次发现 Merleau-Ponty 与 Marion 的 horizon 对立或联系。
